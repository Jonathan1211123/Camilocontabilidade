Razão de Fornecedores · Domínio Sistemas

Envie o razão para conciliar

Casa cada nota fiscal com os pagamentos seguintes (lógica FIFO), confere se o saldo recalculado bate com o Saldo-Exercício do Domínio, e separa o que está correto do que precisa de atenção.

Arraste o arquivo aqui ou clique para escolher
.xls ou .xlsx — exportação de "Razão" do Domínio Sistemas
Requisito do arquivo: exportação do relatório "Razão" do Domínio (menu de Contabilidade), com uma conta por fornecedor. O layout esperado tem, por conta: "Conta:" com o código e nome do fornecedor, uma linha "SALDO ANTERIOR", e lançamentos com Data / Histórico / Débito / Crédito / Saldo.

Se o arquivo for .xls antigo e der erro de leitura: algumas exportações do Domínio geram um binário fora do padrão que o navegador não consegue abrir. Abra o arquivo no Excel ou LibreOffice, use "Salvar como" → .xlsx, e envie o novo arquivo aqui.
